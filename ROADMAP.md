# SGAEIA Roadmap

The roadmap is directional and does not constitute a delivery commitment. Security invariants and evidence quality take precedence over feature count.

## v0.3.2 — GitHub Release Candidate / Public Research Preview

- Public-project governance, licensing, citation, contribution, and disclosure files.
- GitHub issue/PR templates, CI, CodeQL, Dependabot, and release workflow.
- Public-release documentation and repository hardening checklist.

## v0.4.x — Integration Cyber Range

- Deployable SPIRE/OPA/service-mesh/telemetry/message-bus/state-store profiles.
- Failure injection for PDP, identity, network partition, evidence backends, and Edge disconnection.
- Measured revocation propagation and fail-secure evidence.
- IPS-C2 conformance scenarios and generated evidence bundles.

## v0.5.x — Agentic Attack & Defense Lab

- Prompt/indirect prompt injection laboratories.
- Tool abuse, delegation escalation, identity spoofing, RAG/memory poisoning, resource exhaustion, and semantic replacement drift scenarios.
- MITRE ATLAS / OWASP Agentic cross-mapped attack scenarios.
- Reproducible defensive control evaluation.

## v0.6.x — Continuous GRC

- Machine-readable regulatory/control mappings.
- Continuous control monitoring and evidence graph.
- Policy/evidence drift detection.
- GRC knowledge graph reference schema.

## v0.7.x — Edge/MEC High-Assurance Profiles

- K3s/Kubernetes Edge profiles with workload attestation.
- Disconnected sovereign-edge mode.
- Safe degradation and cyber-physical safety barriers.
- IEC 62443-oriented control profile for applicable OT/ICS use cases.

## 1.0 criteria

A 1.0 release should have stable normative interfaces, versioned migration rules, reproducible conformance suites, documented threat coverage, independent review of the core security invariants, and at least one end-to-end deployable reference profile.
