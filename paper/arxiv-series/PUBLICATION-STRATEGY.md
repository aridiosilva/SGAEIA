# SGAEIA Publication Strategy

Submit Paper 01 first as the canonical architecture paper. After it receives an arXiv identifier, cite it from Papers 02–04 and update `CITATION.cff`.

Suggested primary/cross-list categories:
- Paper 01: `cs.AI`, cross-list `cs.CR`, `cs.DC`, `cs.MA`, `cs.NI`.
- Paper 02: `cs.CR`, cross-list `cs.AI`, `cs.MA`, `cs.DC`.
- Paper 03: `cs.SE`, cross-list `cs.CR`, `cs.DC`.
- Paper 04: `cs.CR`, cross-list `cs.AI`, `cs.DC`.

Avoid near-duplicate simultaneous submissions. Each focused paper should state its distinct contribution and cite the architecture paper. After journal/conference acceptance, update the existing arXiv record with journal reference/DOI rather than creating a duplicate.

Recommended artifact chain: GitHub tagged release → Zenodo software DOI → arXiv preprint → peer-reviewed venue → archived reproducibility package.
