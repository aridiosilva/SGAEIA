# Support

SGAEIA is an open reference architecture and research/engineering project. It does not provide an SLA, warranty, production certification, or emergency incident-response service.

For architecture questions, documentation defects, feature proposals, and reproducible bugs, open a GitHub issue after checking existing issues.

For suspected vulnerabilities, credential exposure, bypasses of a security invariant, or sensitive exploit details, **do not open a public issue**. Follow `SECURITY.md`.

For production deployments, safety-critical systems, regulated environments, and OT/ICS use cases, obtain independent security, legal, safety, privacy, and compliance review appropriate to the domain.
