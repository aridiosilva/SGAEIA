# NIST AI RMF Alignment

- **GOVERN:** ownership, policies, risk appetite, agent registry, accountability.
- **MAP:** context, use case, stakeholders, data flows, trust zones, impacts.
- **MEASURE:** ARS, red team, behavior/anomaly, model/tool tests.
- **MANAGE:** PDP/PEP, restrictions, approval, quarantine, kill switch, remediation.

NIST AI 600-1 deve ser consultado para riscos específicos de GenAI.
