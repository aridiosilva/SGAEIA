# IEC 62443 — OT/ICS Applicability

Quando um agente interage com PLCs, SCADA, robôs ou sistemas industriais, aplicar requisitos OT/ICS específicos, zoning/conduits, least functionality, safety barriers, change control e incident response apropriado.

A classificação L4 exige análise de safety independente. O projeto não presume que controles de TI sejam suficientes para sistemas de segurança funcional.
