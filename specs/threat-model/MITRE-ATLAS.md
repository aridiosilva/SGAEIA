# MITRE ATLAS Mapping Strategy

MITRE ATLAS deve ser usado como knowledge base viva para técnicas contra AI-enabled systems, incluindo filtros/plataformas para Generative AI e Agentic AI.

## Processo
1. identificar ativos AI/agentic;
2. selecionar técnicas ATLAS aplicáveis ao deployment;
3. mapear técnicas a attack paths do DFD;
4. ligar cada técnica a controles preventivos/detectivos;
5. manter IDs concretos atualizados no threat register corporativo via processo de revisão.

O projeto evita congelar uma lista de técnicas, pois ATLAS é uma base viva.
