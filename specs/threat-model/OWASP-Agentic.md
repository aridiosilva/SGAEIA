# OWASP Agentic Security Mapping

O projeto adota como princípios:
- agentes devem ser inspectable, traceable e instrumentable;
- controles declarativos devem ser aplicáveis em runtime;
- tool use e delegação devem ser mediados;
- identidade, autorização e observabilidade não podem depender apenas do modelo.

O OWASP Agent Control Standard (ACS), publicado em setembro de 2026, é tratado como referência para hooks de controle/middleware e enforcement em runtime.
