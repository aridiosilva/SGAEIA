This release candidate prepares SGAEIA for its first public GitHub repository. It aligns repository metadata, governance, security reporting, CI, CodeQL, Dependabot, citation metadata, academic paper sources, and publication instructions.

## Assurance statement

`GitHub CI PASS != Production Certification`.

The repository's automated checks demonstrate only the properties covered by their specifications and tests. The adapter harness is contract-level evidence and does not certify upstream products or a production deployment. TLA+/Alloy artifacts are specifications; this release does not claim external model-checker execution.

## Recommended public release label

After the repository is created and the GitHub-hosted checks pass, publish tag `v0.3.2` as a GitHub **Pre-release** titled **SGAEIA v0.3.2 — Public Research Preview**.
