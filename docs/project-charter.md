# Project Charter

## Missão
Fornecer uma arquitetura de referência SDD para sistemas Edge-AI multiagente onde inteligência distribuída não implique autoridade distribuída irrestrita.

## Outcomes
- governança verificável de agentes;
- rastreabilidade requirement→control→policy→evidence;
- decisões de autorização independentes do LLM;
- redução do blast radius;
- autonomia dinâmica e revogável;
- operação Edge fail-secure.

## Fora do escopo
- escolha de fornecedor de LLM;
- modelo regulatório universal;
- safety certification de um setor específico;
- substituição de IAM/PAM/SIEM/GRC corporativos.
