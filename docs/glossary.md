# Glossário

- **Agent-BOM:** inventário de agentes, capabilities, delegações, trust zones e dependências.
- **AIR:** Agent Identity Record.
- **ARS:** Agent Risk Score.
- **ATZ:** Agent Trust Zone.
- **NHI:** Non-Human Identity.
- **PAP:** Policy Administration Point.
- **PDP:** Policy Decision Point.
- **PEP:** Policy Enforcement Point.
- **PoLA:** Principle of Least Agency.
- **SGAEIA:** Secure Governed Autonomous Edge Intelligence Architecture.
- **ZTAM:** Zero-Trust Agentic Mesh.
- **Governed Autonomy:** autonomia explicitamente limitada, observável e revogável.
- **Decision Provenance:** registro suficiente para reconstruir quem/o quê/por quê/quando/política/risco/evidência de uma decisão.
