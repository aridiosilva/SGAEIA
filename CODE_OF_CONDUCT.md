# Code of Conduct

## Our commitment

SGAEIA is intended to be a professional, technically rigorous, and welcoming open-source project. Contributors, maintainers, reviewers, and users are expected to interact respectfully and in good faith.

## Expected behavior

- Discuss ideas, designs, threats, and implementations on their technical merits.
- Be respectful when disagreeing and distinguish critique of work from critique of people.
- Disclose material conflicts of interest when proposing technology choices or security claims.
- Handle vulnerability information according to `SECURITY.md`.
- Do not publish secrets, personal data, exploit payloads against real systems, or confidential evidence in issues or pull requests.
- Clearly label experimental, unverified, or environment-specific claims.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, deliberate disruption, doxxing, credential publication, malicious exploitation of project infrastructure, and knowingly misleading security or certification claims are not acceptable.

## Enforcement

Maintainers may edit or remove content, close issues or pull requests, restrict participation, or take other proportionate action when this policy is violated. Security-sensitive reports should be handled privately using the process in `SECURITY.md`.

## Scope

This Code of Conduct applies to project repositories, discussions, issue trackers, pull requests, review channels, and project-affiliated events or communications.
